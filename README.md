# Campus Wallet

대학생을 위한 생활비 및 지출 관리 웹서비스

## 1. 프로젝트 소개

Campus Wallet은 대학생들이 생활비를 효율적으로 관리할 수 있도록 돕는 개인 가계부 웹서비스입니다.

사용자는 지출을 기록하고, 월별 예산과 소비 현황을 확인할 수 있습니다.

## 2. 개발 환경

- Frontend: React, JavaScript, Vite
- Authentication: Firebase Authentication (구현 예정)
- Database: Cloud Firestore (구현 예정)
- Deployment: JCloud (배포 예정)
- Version Control: Git, GitHub

## 3. 주요 기능

- 생활비 및 지출 현황 표시
- 지출 내역 등록, 조회, 수정, 삭제
- 월별 예산 설정
- 카테고리별 소비 통계
- Firebase 회원가입 및 로그인
- 사용자별 데이터 접근 권한 관리

※ 기능은 단계별로 구현 중입니다.

## 4. 로컬 실행 방법

Node.js 설치 후 다음 명령어를 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173/ 접속
